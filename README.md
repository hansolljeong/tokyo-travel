## 운영 방식

이 문서는 여행 전에 확정 정보를 모으고, 여행 중에는 빠르게 판단하기 위한 knowledge base입니다.

- `확정`: 예약, 티켓, 시간처럼 실제로 정해진 정보
- `후보`: 가고 싶지만 컨디션과 동선에 따라 고를 장소
- `체크 필요`: 운영시간, 예약, 입장 규정처럼 출발 직전에 다시 확인할 것
- `현지 결정`: 날씨, 피로도, Ultra Japan 이후 체력에 맞춰 고를 것
