# 이동 전략

## 기본 원칙

- 도쿄 안에서는 IC 카드 또는 모바일 Suica/PASMO를 기본 결제 수단으로 둔다.
- 숙소 변경일에는 먼저 짐을 맡기고 움직인다.
- Ultra Japan 양일은 오다이바 안에서 동선을 짧게 유지한다.
- 귀국일은 열차 지연을 고려해 보수적으로 움직인다.

## 주요 이동 구간

| 구간 | 기본 전략 | 체크 |
| --- | --- | --- |
| NRT -> 다이몬 | 열차 + 환승 | 도착 터미널, 실시간 경로 |
| 다이몬 -> 다이바 | 대중교통 또는 택시 | 체크아웃 후 짐 보관 |
| 다이바 <-> Ultra Japan | 도보/대중교통 | 행사장 입구 위치 |
| 다이바 -> 메구로 아오바다이 | 대중교통 | 체크인 전 짐 보관 |
| 메구로 아오바다이 -> NRT | N'EX 또는 Skyliner 계열 | 출발 1편 여유 |

## 택시를 고려할 만한 순간

- 숙소 변경일에 짐이 많고 피곤할 때
- Ultra Japan 종료 후 대중교통 혼잡이 심할 때
- 비가 오거나 컨디션이 급격히 떨어졌을 때

## 지도 세팅

- 모든 숙소를 Google Maps/Apple Maps에 저장
- Ultra Japan 행사장 저장
- 나리타공항 터미널 저장
- 지도에 저장한 레코드바/사우나를 `03-places`에 옮겨오기

## 출발 전 캡처할 것

- 항공권
- 숙소 예약 화면
- Ultra Japan 티켓/AnyPASS 화면
- 나리타-숙소 이동 경로
- 마지막 날 숙소-나리타 이동 경로
- 여권 사진면은 보안상 로컬 암호화/클라우드 보안 위치에만 보관
